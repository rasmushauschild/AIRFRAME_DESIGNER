        Bench test 
        

          

            
            
            
            
          

          
Carried by hand, PX4 fuses a zero-velocity observation every 200 ms (its land detector says
            at rest: landed, and turning slower than 3°/s), so the H-flow can be tracking perfectly and the
            model still will not move. This stops the land detector for as long as the board stays powered, which
            leaves at rest false and lets the flow drive the position. It is not written to flash and a
            reboot undoes it. Put it back before the aircraft flies — without a land detector PX4 cannot tell
            that it has landed.
